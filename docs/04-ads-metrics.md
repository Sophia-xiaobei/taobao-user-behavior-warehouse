# 04 · ADS 指标层与分析结论

## 1. ADS 层定位

ADS（应用数据服务层）直接面向业务问题，回答"业务怎么样、健康吗"。所有指标基于 DWS/DIM 层计算，不再扫描 989 万行明细——这正是数仓分层"用空间换时间"价值的体现。

> 说明：数据集无价格字段，无法计算真实 GMV，本层以购买件数/购买人数作为成交指标替代；真实业务中关联商品价格表即可扩展出 GMV 口径。

## 2. 指标一：每日大盘总览（ads_daily_overview）

**指标口径**：

| 指标 | 口径 |
|---|---|
| pv / uv | 当日浏览量 / 当日有行为的独立用户数 |
| cart_user_cnt / buy_user_cnt | 当日有加购 / 有购买行为的人数 |
| buy_cnt | 当日购买件数 |
| pv_to_buy_rate | 浏览-购买转化率 = buy_user_cnt / uv × 100% |

**计算 SQL**：基于 `dws.dws_user_action_1d` 按 dt 分组聚合。

## 4. 指标三：复购率（ads_repurchase_summary）

**口径**：复购用户 = 在不同日期购买 ≥2 次的用户；复购率 = 复购用户数 / 总购买用户数。

**结果**：总购买用户164442，复购用户20525，复购率 12.48%，购买用户平均购买1.14天。

## 5. 指标四：RFM 用户分层（ads_rfm_user）

**模型说明**：
- R（Recency）：距最近购买的天数（以数据集末日 2017-12-03 为基准），分 5 档；
- F（Frequency）：累计购买件数，分 5 档；
- M（Monetary）：数据集无价格，以购买件数近似（已在 F 中体现）。

**打分规则**：

| 分数 | R：距最后购买 | F：累计购买件数 |
|---|---|---|
| 5 | ≤1 天 | ≥10 件 |
| 4 | 2-3 天 | 6-9 件 |
| 3 | 4-5 天 | 4-5 件 |
| 2 | 6-7 天 | 2-3 件 |
| 1 | ≥8 天 | 1 件 |

**分层结果**：

| 用户分层 | 人数 | 占比 | 运营策略 |
|---|---|---|---|
| 重要价值用户 | 146 | 0.09% | 重点维护，VIP 服务与新品优先触达 |
| 重要发展用户 | 79038 | 48.06% | 发放优惠券刺激复购，提升购买频次 |
| 重要保持用户 | 8 | 0.005% | 召回提醒，防止高价值用户流失 |
| 一般用户 | 85250 | 51.84% | 常规内容触达 |

## 6. 业务结论（核心产出）

1. **漏斗结论**：浏览→购买转化率仅 **17.23%**，其中加购→购买转化率为 **51.13%**，而浏览→加购转化率仅 **33.70%**，说明主要流失发生在“浏览→加购”环节。建议优化商品详情页和推荐算法，或向浏览未加购用户发放“加购专属优惠券”刺激加购。

2. **复购结论**：复购率 **12.48%**，低于电商行业平均水平（约 20%-40%），9 天内仅约 1/8 的购买用户产生复购。建议对已购用户在购买后 3 天内推送关联商品或复购券，提升用户生命周期价值。

3. **分层结论**：一般用户（51.84%）和重要发展用户（48.06%）合计占 **99.9%**，重要价值用户仅 146 人（0.09%）。由于数据集仅 9 天且缺少真实消费金额，高价值用户尚未充分沉淀。建议**将营销资源向“重要发展用户”倾斜**，通过精准触达将其转化为重要价值用户。

## 7. 指标血缘（分层价值佐证）

```
dwd.dwd_user_behavior (989万行明细)
    ├─→ dim.dim_user ────────────→ ads_conversion_funnel（漏斗）
    ├─→ dws.dws_user_action_1d ──→ ads_daily_overview（大盘）
    ├─→ dwd 直接聚合 ────────────→ ads_repurchase_summary（复购）
    └─→ dwd 直接聚合 ────────────→ ads_rfm_user（RFM）
```
ADS 层所有指标的计算均基于汇总/维度表，无需回扫明细，查询耗时从分钟级降至秒级。
